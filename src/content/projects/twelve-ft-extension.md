A Chrome Extension that automates the redirect to [12ft.io](https://12ft.io) for paywalled articles. Before this existed, you had to manually prepend the URL, which was annoying enough that I built a button instead.

Small project, real utility. Built in an afternoon, used daily.

**Stack:** HTML, JavaScript, Chrome Extension API
